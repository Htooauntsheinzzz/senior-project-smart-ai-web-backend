# 5. Final Courses Table Attributes

| Column | Data Type | Constraint | Description |
|---|---|---|---|
| `id` | BIGINT | PK, Identity | Internal Course ID |
| `course_code` | VARCHAR(50) | UNIQUE, NOT NULL | Course business code |
| `course_name` | VARCHAR(255) | NOT NULL | Course name |
| `credit_hours` | INTEGER | NOT NULL | Credit hours |
| `description` | VARCHAR(1000) | NULL | Course description |
| `faculty_id` | BIGINT | FK → `faculties.id`, NOT NULL | Faculty |
| `department_id` | BIGINT | FK → `departments.id`, NOT NULL | Department |
| `program_id` | BIGINT | FK → `programs.id`, NULL | Program/Major |
| `semester_id` | BIGINT | FK → `semesters.id`, NULL | Recommended Semester |
| `recommended_academic_year` | SMALLINT | NULL | Recommended Year 1, 2, 3, etc. |
| `prerequisite_courses` | VARCHAR(1000) | NULL | Prerequisite course codes |
| `course_type` | SMALLINT | NOT NULL | Numeric Course Type enum code |
| `maximum_students_per_section` | INTEGER | NULL | Maximum number of students |
| `is_active` | BOOLEAN | NOT NULL DEFAULT TRUE | Active/Inactive |
| `is_deleted` | BOOLEAN | NOT NULL DEFAULT FALSE | Soft-delete flag |
| `created_by` | BIGINT | FK → `app_users.id`, NOT NULL | Creator |
| `created_at` | TIMESTAMP | NOT NULL DEFAULT CURRENT_TIMESTAMP | Created timestamp |
| `updated_by` | BIGINT | FK → `app_users.id`, NULL | Last updater |
| `updated_at` | TIMESTAMP | NULL | Updated timestamp |

# 22. Prerequisite Course Validation

Although prerequisites are stored in one column, the future backend should validate each provided Course Code.

Example:

```text
CS101,CS201
```

Backend should:

```text
Split by comma
        ↓
Trim each code
        ↓
Check each Course Code exists
        ↓
Reject current Course as its own prerequisite
        ↓
Store normalized string
```

Example invalid:

```text
Course Code:
CS301

Prerequisite:
CS301
```

must be rejected by application logic.

This validation is not implemented in the Flyway migration.

```java
public enum CourseType {

    GENERAL_EDUCATION(100, "General Education"),

    MAJOR_ELECTIVE(200, "Major Elective"),

        this.code = code;
        this.displayName = displayName;
    }

    public int getCode() {
        return code;
    }

    public String getDisplayName() {
        return displayName;
    }
}
```

# 34. Required SQL

```sql
CREATE TABLE courses (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,

    course_code VARCHAR(50) NOT NULL,

    course_name VARCHAR(255) NOT NULL,

    credit_hours INTEGER NOT NULL,

    description VARCHAR(1000),

    faculty_id BIGINT NOT NULL,

    department_id BIGINT NOT NULL,

    program_id BIGINT,

    semester_id BIGINT,

    recommended_academic_year SMALLINT,

    prerequisite_courses VARCHAR(1000),

    course_type SMALLINT NOT NULL,

    maximum_students_per_section INTEGER,

    is_active BOOLEAN NOT NULL DEFAULT TRUE,

    is_deleted BOOLEAN NOT NULL DEFAULT FALSE,

    created_by BIGINT NOT NULL,

    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_by BIGINT,

    updated_at TIMESTAMP,

    CONSTRAINT uk_courses_course_code
        UNIQUE (course_code),

    CONSTRAINT chk_courses_credit_hours
        CHECK (
            credit_hours > 0
        ),

    CONSTRAINT chk_courses_recommended_academic_year
        CHECK (
            recommended_academic_year IS NULL
            OR recommended_academic_year > 0
        ),

    CONSTRAINT chk_courses_course_type
        CHECK (
            course_type IN (100, 200, 300)
        ),

    CONSTRAINT chk_courses_maximum_students
        CHECK (
            maximum_students_per_section IS NULL
            OR maximum_students_per_section > 0
        ),

    CONSTRAINT fk_courses_faculty
        FOREIGN KEY (faculty_id)
        REFERENCES faculties(id),

    CONSTRAINT fk_courses_department
        FOREIGN KEY (department_id)
        REFERENCES departments(id),

    CONSTRAINT fk_courses_program
        FOREIGN KEY (program_id)
        REFERENCES programs(id),

    CONSTRAINT fk_courses_semester
        FOREIGN KEY (semester_id)
        REFERENCES semesters(id),

    CONSTRAINT fk_courses_created_by
        FOREIGN KEY (created_by)
        REFERENCES app_users(id),

    CONSTRAINT fk_courses_updated_by
        FOREIGN KEY (updated_by)
        REFERENCES app_users(id)
);
```

# 53. Acceptance Criteria

## Basic Information

```text
[ ] courses table exists

[ ] id is BIGINT Identity PK

[ ] course_code is UNIQUE and NOT NULL

[ ] course_name is NOT NULL

[ ] credit_hours is INTEGER and > 0

[ ] description is nullable
```

## Academic Classification

```text
[ ] faculty_id references faculties.id

[ ] department_id references departments.id

[ ] program_id references programs.id

[ ] program_id is nullable

[ ] semester_id references semesters.id

[ ] semester_id is nullable

[ ] recommended_academic_year is nullable

[ ] recommended_academic_year must be positive when provided
```

## Prerequisite Courses

```text
[ ] prerequisite_courses exists in courses

[ ] prerequisite_courses is VARCHAR(1000)

[ ] prerequisite_courses is nullable

[ ] Comma-separated codes can be stored

[ ] Future backend validates prerequisite Course Codes
```

## Course Type

```text
[ ] course_type exists

[ ] course_type is SMALLINT

[ ] 100 = General Education

[ ] 200 = Major Elective

[ ] 300 = Major Required

[ ] Only 100, 200, 300 are accepted
```

## Maximum Students

```text
[ ] maximum_students_per_section exists

[ ] maximum_students_per_section is INTEGER

[ ] maximum_students_per_section is nullable

[ ] Value must be greater than 0 when provided
```

## Status

```text
[ ] is_active defaults TRUE
```
