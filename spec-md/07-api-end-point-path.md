# 07 - Admin Web API Path Convention Specification

## 1. Project

**Smart University Student Assistant App**

This specification defines the API path convention for the **Admin Web Application**.

All Admin Web APIs must start with the following base path:

```text
/api/v1/admin
Local development base URL:
http://localhost:8080/api/v1/admin
2. Mandatory API Base Path
Every Admin Web feature must use:
/api/v1/admin/{feature}
```
