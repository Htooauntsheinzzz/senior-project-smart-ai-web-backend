# 2. Important Icon Rule

The Faculty UI contains Faculty icons.

However, icons are **frontend presentation data** and must NOT be stored in the Faculty database.

Do NOT create:

```text
icon
icon_key
icon_name
icon_url
icon_path
icon_data
```

inside the `faculties` table.

The Admin Web frontend is responsible for displaying Faculty icons.

Example:

```text
FAC-ENG
    ↓
Frontend UI mapping
    ↓
Engineering Icon
```

This mapping does NOT belong in PostgreSQL.

# 7. Normalized Table Attributes

| Column | Data Type | Constraint | Description |
|---|---|---|---|
| `id` | BIGINT | PK, Identity | Internal Faculty ID |
| `faculty_code` | VARCHAR(30) | UNIQUE, NOT NULL | Faculty code such as `FAC-ENG` |
| `faculty_name_en` | VARCHAR(255) | UNIQUE, NOT NULL | Faculty English name |
| `faculty_name_th` | VARCHAR(255) | NULL | Faculty Thai name |
| `is_active` | BOOLEAN | NOT NULL DEFAULT TRUE | Active/Inactive status |
| `is_deleted` | BOOLEAN | NOT NULL DEFAULT FALSE | Soft-delete flag |
| `created_by` | BIGINT | FK → `app_users.id`, NOT NULL | Admin who created the Faculty |
| `created_at` | TIMESTAMP | NOT NULL DEFAULT CURRENT_TIMESTAMP | Creation time |
| `updated_by` | BIGINT | FK → `app_users.id`, NULL | Admin who last updated the Faculty |
| `updated_at` | TIMESTAMP | NULL | Last update time |

# 23. Required Migration SQL

```sql
CREATE TABLE faculties (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,

    faculty_code VARCHAR(30) NOT NULL,

    faculty_name_en VARCHAR(255) NOT NULL,

    faculty_name_th VARCHAR(255),

    is_active BOOLEAN NOT NULL DEFAULT TRUE,

    is_deleted BOOLEAN NOT NULL DEFAULT FALSE,

    created_by BIGINT NOT NULL,

    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_by BIGINT,

    updated_at TIMESTAMP,

    CONSTRAINT uk_faculties_faculty_code
        UNIQUE (faculty_code),

    CONSTRAINT uk_faculties_faculty_name_en
        UNIQUE (faculty_name_en),

    CONSTRAINT fk_faculties_created_by
        FOREIGN KEY (created_by)
        REFERENCES app_users(id),

    CONSTRAINT fk_faculties_updated_by
        FOREIGN KEY (updated_by)
        REFERENCES app_users(id)
);
```

# 24. Required Indexes

Do NOT create duplicate indexes for:

```text
faculty_code
faculty_name_en
```

because their UNIQUE constraints already create indexes.

Create:

```sql
CREATE INDEX idx_faculties_is_active
    ON faculties(is_active);

CREATE INDEX idx_faculties_is_deleted
    ON faculties(is_deleted);

CREATE INDEX idx_faculties_created_by
    ON faculties(created_by);

CREATE INDEX idx_faculties_updated_by
    ON faculties(updated_by);
```

Optional:

```sql
CREATE INDEX idx_faculties_active_not_deleted
    ON faculties(is_active, is_deleted);
```

Avoid unnecessary duplicate indexes.
