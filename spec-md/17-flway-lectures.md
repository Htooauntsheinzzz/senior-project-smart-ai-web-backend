# 4. Table Purpose

The `lectures` table stores university lecture/lecturer master information.

Each Lecture record belongs to:

```text
one Faculty
one Department
```

Relationship:

```text
Faculty
   1
   │
   │
   N
Lectures

Department
   1
   │
   │
   N
Lectures
```

---

# 5. Required Table Attributes

| Column | Data Type | Constraint | Description |
|---|---|---|---|
| `id` | BIGINT | PK, Identity | Internal Lecture ID |
| `lecture_name_th` | VARCHAR(255) | NOT NULL | Lecture name in Thai |
| `lecture_name_en` | VARCHAR(255) | NOT NULL | Lecture name in English |
| `lecture_nickname` | VARCHAR(100) | NULL | Lecture nickname |
| `faculty_id` | BIGINT | FK → `faculties.id`, NOT NULL | Related Faculty |
| `department_id` | BIGINT | FK → `departments.id`, NOT NULL | Related Department |
| `status` | VARCHAR(30) | NOT NULL DEFAULT `'ACTIVE'` | Lecture status |
| `is_deleted` | BOOLEAN | NOT NULL DEFAULT FALSE | Soft-delete flag |
| `created_by` | BIGINT | FK → `app_users.id`, NOT NULL | Admin who created record |
| `created_at` | TIMESTAMP | NOT NULL DEFAULT CURRENT_TIMESTAMP | Created timestamp |
| `updated_by` | BIGINT | FK → `app_users.id`, NULL | Admin who last updated record |
| `updated_at` | TIMESTAMP | NULL | Last updated timestamp |

# 13. Faculty and Department Consistency

Both foreign keys are required by this feature:

```text
faculty_id
department_id
```

The database guarantees that both IDs exist.

The future CRUD service must additionally verify:

```text
selected Department belongs to selected Faculty
```

Concept:

```text
facultyId
    ↓
Faculty exists

departmentId
    ↓
Department exists
    ↓
department.faculty_id == facultyId
```

This cross-table business validation belongs in the service layer.

# 21. Name Duplicate Rule

Do not make Thai or English name globally unique individually.

Different Faculties or Departments could potentially have similar names.

Prevent an exact duplicate Lecture inside the same Department.

Recommended unique combination:

```text
department_id
+
lecture_name_th
+
lecture_name_en
```

Constraint:

```sql
CONSTRAINT uk_lectures_department_names
UNIQUE (
    department_id,
    lecture_name_th,
    lecture_name_en
)
```

# 25. Required Migration SQL

```sql
CREATE TABLE lectures (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,

    lecture_name_th VARCHAR(255) NOT NULL,

    lecture_name_en VARCHAR(255) NOT NULL,

    lecture_nickname VARCHAR(100),

    faculty_id BIGINT NOT NULL,

    department_id BIGINT NOT NULL,

    status VARCHAR(30) NOT NULL DEFAULT 'ACTIVE',

    is_deleted BOOLEAN NOT NULL DEFAULT FALSE,

    created_by BIGINT NOT NULL,

    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_by BIGINT,

    updated_at TIMESTAMP,

    CONSTRAINT uk_lectures_department_names
        UNIQUE (
            department_id,
            lecture_name_th,
            lecture_name_en
        ),

    CONSTRAINT chk_lectures_status
        CHECK (
            status IN ('ACTIVE', 'INACTIVE')
        ),

    CONSTRAINT fk_lectures_faculty
        FOREIGN KEY (faculty_id)
        REFERENCES faculties(id),

    CONSTRAINT fk_lectures_department
        FOREIGN KEY (department_id)
        REFERENCES departments(id),

    CONSTRAINT fk_lectures_created_by
        FOREIGN KEY (created_by)
        REFERENCES app_users(id),

    CONSTRAINT fk_lectures_updated_by
        FOREIGN KEY (updated_by)
        REFERENCES app_users(id)
);
```

# 26. Required Indexes

The unique constraint already creates an index for:

```text
department_id
+
lecture_name_th
+
lecture_name_en
```

Do NOT duplicate that exact index.

Create:

```sql
CREATE INDEX idx_lectures_faculty_id
    ON lectures(faculty_id);

CREATE INDEX idx_lectures_department_id
    ON lectures(department_id);

CREATE INDEX idx_lectures_status
    ON lectures(status);

CREATE INDEX idx_lectures_is_deleted
    ON lectures(is_deleted);

CREATE INDEX idx_lectures_created_by
    ON lectures(created_by);

CREATE INDEX idx_lectures_updated_by
    ON lectures(updated_by);
```

Recommended composite index:

```sql
CREATE INDEX idx_lectures_department_status_deleted
    ON lectures(
        department_id,
        status,
        is_deleted
    );
```
