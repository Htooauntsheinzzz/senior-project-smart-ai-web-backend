# 16 - Semester Flyway Migration Specification

## 1. Project

**Smart University Student Assistant App**

This specification defines the Flyway migration for the new:

```text
Academic Management
    ↓
Semester
```

The Semester feature represents semester names used for the university school year/academic structure.

This task is **Flyway migration only**.

Do NOT implement yet:

- Semester Entity
- Semester Repository
- Semester DTO
- Semester Mapper
- Semester Service
- Semester Controller
- Semester CRUD API
- Redis Cache
- Academic Year relationship

# 4. Table Purpose

The `semesters` table stores semester names in both:

```text
Thai
English
```

Example:

```text
semester_name_th = ภาคการศึกษาที่ 1
semester_name_en = Semester 1
```

Another example:

```text
semester_name_th = ภาคการศึกษาที่ 2
semester_name_en = Semester 2
```

---

# 5. Required Table Attributes

Use the following normalized structure:

| Column | Data Type | Constraint | Description |
|---|---|---|---|
| `id` | BIGINT | PK, Identity | Internal Semester ID |
| `semester_name_th` | VARCHAR(150) | NOT NULL | Semester name in Thai |
| `semester_name_en` | VARCHAR(150) | NOT NULL | Semester name in English |
| `is_deleted` | BOOLEAN | NOT NULL DEFAULT FALSE | Soft-delete flag |
| `created_by` | BIGINT | FK → `app_users.id`, NOT NULL | Admin who created the record |
| `created_at` | TIMESTAMP | NOT NULL DEFAULT CURRENT_TIMESTAMP | Created timestamp |
| `updated_by` | BIGINT | FK → `app_users.id`, NULL | Admin who last updated the record |
| `updated_at` | TIMESTAMP | NULL | Last update timestamp |

# 10. Semester Name Uniqueness

A duplicate Thai/English Semester combination should not be created.

Add:

```sql
UNIQUE (
    semester_name_th,
    semester_name_en
)
```

Example duplicate:

```text
ภาคการศึกษาที่ 1
Semester 1
```

must not exist more than once.

Recommended constraint name:

```text
uk_semesters_name_th_en
```

# 19. Required Migration SQL

```sql
CREATE TABLE semesters (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,

    semester_name_th VARCHAR(150) NOT NULL,

    semester_name_en VARCHAR(150) NOT NULL,

    is_deleted BOOLEAN NOT NULL DEFAULT FALSE,

    created_by BIGINT NOT NULL,

    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,

    updated_by BIGINT,

    updated_at TIMESTAMP,

    CONSTRAINT uk_semesters_name_th_en
        UNIQUE (
            semester_name_th,
            semester_name_en
        ),

    CONSTRAINT fk_semesters_created_by
        FOREIGN KEY (created_by)
        REFERENCES app_users(id),

    CONSTRAINT fk_semesters_updated_by
        FOREIGN KEY (updated_by)
        REFERENCES app_users(id)
);
```

---

# 20. Recommended Indexes

The unique constraint already provides an index for:

```text
semester_name_th + semester_name_en
```

Do NOT create a duplicate index for that combination.

Create:

```sql
CREATE INDEX idx_semesters_is_deleted
    ON semesters(is_deleted);

CREATE INDEX idx_semesters_created_by
    ON semesters(created_by);

CREATE INDEX idx_semesters_updated_by
    ON semesters(updated_by);
```
